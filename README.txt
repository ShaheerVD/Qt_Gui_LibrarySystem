Qt Gui Library Management System

This is a library management system built with C++ and QT Widgets.
It allows users to manage a collection of books and magazines, including adding, searching, borrowing, and returning items. 
The data is saved in a text file for future use.

Features:
1.Adding Books,Magazines
2.Searching for Books,Magazines
3.Borrowing Books,Magazines
4.Returning Books,Magazines
5.Displaying all Books,Magazines

Setup Instructions:
-Qt Creator is required

1.Open the project files in Qt creator
2.Build and run the project in Qt
3.The Library data file is created on first startup if it does not exist in the build folder already

Data Format:
Book format: ID|Book|Title|Author|IsBorrowed|Genre|PageCount
Magazine format: ID|Magazine|Title|Author|IsBorrowed|IssueNumber|PublicationDate
